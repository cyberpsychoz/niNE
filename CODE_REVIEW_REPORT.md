## Выявленные проблемы (не исправленные)

### Средний приоритет

#### 1. Отсутствие проверки дубликатов unique_id
**Локация:** `nine/core/plugins.py`

**Проблема:** PluginManager не проверяет дубликаты `unique_id` при загрузке плагинов

**Рекомендация:**
```python
# В PluginManager._load_plugin()
if plugin_info.unique_id in self.loaded_plugins:
    self.logger.warning(
        f"Plugin '{plugin_info.unique_id}' already loaded! "
        f"Skipping duplicate from {plugin_dir}"
    )
    return
```

**Файл:** `nine/core/plugins.py:274`

---

#### 2. UIManager использует каскадные destroy
**Локация:** `nine/ui/manager.py`

**Проблема:** Методы типа `show_main_menu()` вызывают множественные `_destroy_component()` для всех возможных состояний

**Рекомендация:** Использовать явный state machine или перейти на declarative UI states

**Файл:** `nine/ui/manager.py` (строки 201, 240, и др.)

---

### Низкий приоритет

#### 3. Отсутствие type hints в старом коде
**Проблема:** `entity.py` и старые модули не используют type hints

**Рекомендация:** Постепенно добавлять type hints при рефакторинге

---

#### 4. Network sync без дельта-сжатия
**Локация:** `nine/core/systems.py` - `NetworkSyncSystem`

**Проблема:** `get_world_state()` сериализует ВСЕ pawns каждый кадр

**Рекомендация:** Реализовать дельта-синхронизацию для оптимизации сети при 300+ NPC
