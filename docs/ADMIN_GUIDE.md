## Роли пользователей

В системе есть три роли:

| Роль | Описание | Права |
|------|----------|-------|
| `player` | Обычный игрок | Базовые команды, RP чат |
| `dm` | Игровой мастер | + админ-команды, управление боями |
| `admin` | Администратор | Все права + управление сервером |

### Как назначить роль

Роль хранится в базе данных (`nine.db`), таблица `players`, поле `role`.

```sql
-- Через SQLite CLI или DB Browser
UPDATE players SET role = 'admin' WHERE name = 'НикИгрока';
UPDATE players SET role = 'dm' WHERE name = 'НикИгрока';
```

## Команды чата

### Команды для всех игроков

| Команда | Описание | Пример |
|---------|----------|--------|
| `/me <действие>` | Действие от первого лица | `/me машет рукой` |
| `/it <текст>` | Безличное действие | `/it Ветер усиливается` |
| `/looc <текст>` | Локальный OOC (в радиусе) | `/looc Подожди минуту` |
| `/ooc <текст>` | Глобальный OOC | `/ooc Всем привет!` |
| `/help` | Список доступных команд | `/help` |
| `/give <id> [кол-во]` | Выдать предмет себе | `/give health_potion 5` |
| `/spawn <id> [кол-во]` | Заспавнить предмет | `/spawn iron_sword` |
| `/items` | Список доступных предметов | `/items` |

### Команды для админов (dm/admin)

| Команда | Описание | Пример |
|---------|----------|--------|
| `/charsetmodel <модель>` | Изменить модель персонажа | `/charsetmodel human_male` |
| `/charsetfaction <фракция>` | Изменить фракцию | `/charsetfaction guards` |

### Команды боевой системы (планируется)

| Команда | Описание | Пример |
|---------|----------|--------|
| `/startcombat [радиус]` | Начать бой с NPC в радиусе | `/startcombat 30` |
| `/endcombat` | Завершить текущий бой | `/endcombat` |
| `/nextturn` | Принудительно следующий ход | `/nextturn` |
| `/setinit <id> <значение>` | Установить инициативу | `/setinit player1 15` |
| `/addtocombat <id>` | Добавить в текущий бой | `/addtocombat goblin_1` |
| `/spectator` | Режим спектатора (свободная камера) | `/spectator` |

### Команды аудио (планируется)

| Команда | Описание | Пример |
|---------|----------|--------|
| `/music play <плейлист>` | Включить музыку | `/music play combat` |
| `/music stop [fadeout]` | Остановить музыку | `/music stop 2` |
| `/music track <файл>` | Включить конкретный трек | `/music track tavern.ogg` |
| `/ambient set <зона>` | Установить эмбиент | `/ambient set forest_day` |
| `/ambient stop` | Остановить эмбиент | `/ambient stop` |
| `/sfx play <звук>` | Воспроизвести звук | `/sfx play sword_hit` |
| `/volume master <0-100>` | Громкость | `/volume master 50` |

## Управление предметами

### Доступные предметы

Используйте `/items` чтобы увидеть все доступные предметы.

**Базовые предметы:**
- `health_potion` - Зелье здоровья
- `iron_sword` - Железный меч
- `n_bucks` - Валюта
- `sushi` - Еда

**Оружие D&D (примеры):**
- `longsword` - Длинный меч
- `shortsword` - Короткий меч
- `greataxe` - Большой топор
- `longbow` - Длинный лук
- `dagger` - Кинжал
- `rapier` - Рапира

**Броня D&D (примеры):**
- `leather_armor` - Кожаная броня
- `chainmail` - Кольчуга
- `plate_armor` - Латы
- `steel_shield` - Стальной щит

**Магические аксессуары (примеры):**
- `ring_of_protection` - Кольцо защиты (+1 AC)
- `cloak_of_elvenkind` - Эльфийский плащ
- `boots_of_speed` - Сапоги скорости
- `amulet_of_health` - Амулет здоровья

### Выдача предметов игрокам

```
/give longsword          -- выдать 1 длинный меч себе
/give health_potion 10   -- выдать 10 зелий здоровья себе
```

> **Примечание:** Пока нет команды выдать предмет другому игроку. Игрок должен быть рядом и использовать команду сам, либо выдавать через прямое редактирование БД.

## Управление персонажами

### Изменение модели

Доступные модели (из `sh_constants.py`):
- `human_male`, `human_female`
- `elf_male`, `elf_female`
- `dwarf_male`, `dwarf_female`
- И другие (зависят от доступных ассетов)

```
/charsetmodel human_male
```

### Изменение фракции

Доступные фракции:
- `alliance` - Альянс (синий)
- `horde` - Орда (красный)
- `neutral` - Нейтралы (серый)
- `undead` - Нежить (фиолетовый)

```
/charsetfaction alliance
```

## Проведение боёв (планируется)

> **Статус:** Код боевой системы написан, но пока не интегрирован в плагины. Команды ниже будут работать после интеграции.

### Начало боя

1. Убедитесь, что рядом есть враждебные NPC
2. Используйте `/startcombat 30` (30 - радиус в футах)
3. Все враждебные NPC и игроки в радиусе добавятся в бой
4. Бросается инициатива, определяется порядок ходов

### Во время боя

- **Порядок ходов** отображается в панели слева
- **Действия** выбираются в панели снизу (Атака, Рывок, Уклонение и т.д.)
- **Движение** - кликните на клетку для перемещения
- **Атака** - выберите цель курсором

### Управление DM

```
/nextturn              -- пропустить ход текущего участника
/setinit goblin_1 20   -- установить инициативу NPC
/addtocombat wolf_1    -- добавить NPC в текущий бой
/endcombat             -- принудительно завершить бой
```

### Режим спектатора

```
/spectator             -- включить/выключить режим спектатора
```

В режиме спектатора:
- WASD + Space/Ctrl - свободный полёт камеры
- Shift - ускорение
- Мышь - поворот камеры

## Устранение проблем

### Ошибки импорта при запуске

Если видите `ImportError: attempted relative import with no known parent package`:
- Это обычно означает проблему с путями импорта в плагинах
- Проверьте что используются абсолютные импорты (`from nine.plugins.inventory...`)
- Перезапустите сервер

### Игрок застрял

1. Попросите игрока перезайти
2. Если не помогает - измените позицию в БД:
```sql
UPDATE game_characters SET pos_x = 0, pos_y = 0, pos_z = 1 WHERE name = 'ИмяПерсонажа';
```

### Инвентарь не синхронизируется

1. Игрок должен нажать Tab чтобы обновить инвентарь
2. Проверьте логи сервера на ошибки
3. Перезапустите сервер

### Чат не работает

1. Проверьте что чат открыт (клавиша T)
2. Проверьте что игрок в игре (не в меню)
3. Проверьте логи на ошибки плагина чата
