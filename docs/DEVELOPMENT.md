# D&D Режим (Отдельная ветка)

**ВАЖНО:** D&D режим — это **отдельная ветка разработки**, не влияющая на основное развитие niNE. Основной проект niNE продолжит развиваться независимо.

**Цель:** Создать специализированный режим для онлайн-сессий D&D с пошаговой боевой системой, расширенным управлением персонажами и инструментами для Игрового Мастера.

**Статус:** Отдельная ветка на основе стабильной версии **niNE 0.1.0-alpha**

**Принцип разработки:** Изменения **ТОЛЬКО в плагинах** (`nine/plugins/dnd/`). Ядро niNE остаётся неизменным, что позволяет:
- Легко мерджить обновления из основной ветки
- Не ломать базовый функционал niNE
- Использовать D&D режим как опциональное расширение

#### Реализованный код:

**Плагин `nine/plugins/combat/` — боевая система в стиле Baldur's Gate 3:**

- `sh_dice.py` — система бросков кубов D&D:
  - `DiceRoller.roll("2d6+3")` — парсинг и бросок любых кубов
  - `roll_initiative(dex_mod)` — инициатива d20 + DEX
  - `roll_attack(bonus, advantage, disadvantage)` — атака с преимуществом/помехой
  - `roll_damage(dice, critical)` — урон с удвоением при критическом ударе
  - Поддержка преимущества (advantage) и помехи (disadvantage)

- `sh_action_economy.py` — экономика действий D&D 5e:
  - Действия: Атака, Рывок, Отход, Уклонение, Помощь, Подготовка
  - Типы стоимости: ACTION, BONUS, REACTION, MOVEMENT, NONE
  - Система состояний (conditions): Оглушён, Испуган, Отравлен и др.
  - Типы целей: NONE, SELF, SINGLE, AREA, ALL

- `sv_combat_manager.py` — серверный менеджер боёв:
  - Управление боевыми сессиями (`CombatInstance`)
  - Участники боя (`CombatParticipant`) с HP, AC, инициативой
  - Автоматический бой при агро NPC
  - Ручной старт боя игроками
  - Принудительный контроль DM

- `sv_turn_manager.py` — управление ходами:
  - Валидация действий (ресурсы, дальность, состояния)
  - Выполнение атак по правилам D&D (d20 vs AC)
  - Расчёт урона с модификаторами
  - Проверка дистанции между сущностями
  - Автопереход к следующему ходу

**Клиентский UI (`cl_*`):**

- `cl_target_selector.py` — выбор целей курсором:
  - Клавиша **C** переключает между режимом камеры и курсора
  - Raycasting для определения цели под курсором
  - Подсветка при наведении, индикатор выбора
  - Авто-включение курсора при входе в бой

- `cl_initiative_display.py` — панель инициативы (слева):
  - Вертикальный список участников боя
  - Имя, HP-бар, число инициативы
  - Подсветка текущего хода (зелёный)
  - Обновление HP в реальном времени

- `cl_action_bar.py` — панель действий (снизу):
  - Кнопки: Атака (1), Рывок (2), Отход (3), Уклонение (4), Помощь (5), Конец хода (E)
  - Индикаторы ресурсов: движение (футы), действие, бонус, реакция
  - Активация только в ваш ход
  - Горячие клавиши 1-5, E

- `cl_combat_ui.py` — главный координатор UI боя:
  - Индикатор хода ("ВАШ ХОД!" / "Ход: Имя")
  - Результаты действий (попадание, промах, критический удар)
  - Баннеры начала/окончания боя
  - Логирование в чат

- `cl_spectator_mode.py` — режим спектатора для GM/DM:
  - Свободный полёт камеры (WASD + Space/Ctrl)
  - Shift для ускорения

**GM-команды в чате (`sv_broadcast.py`):**

- **Плагины server-side:** Логика боевой системы, управление инициативой, броски кубов
- **Плагины client-side:** UI для листа персонажа, отображение боевого режима, инструменты DM
- **Плагины common:** Общие константы D&D (классы, расы, заклинания)

**Никаких изменений в core-модулях niNE!** Вся функциональность D&D добавляется через события и плагины.

### Фаза 0: Система персонажей и кастомизации (Приоритет: КРИТИЧЕСКИЙ)

**ВАЖНО:** Эта фаза должна быть реализована **ДО** всех остальных D&D механик, так как она является фундаментом для игрового опыта.

#### A. Экран выбора/создания персонажа

**Цель:** При входе в игру после авторизации показывать меню управления персонажами вместо немедленного спавна.

**Поток авторизации:**
```
1. Main Menu → Login
2. Успешная авторизация (auth/dev_auth)
3. ❌ СТАРОЕ: Сразу спавн в мире
4. ✅ НОВОЕ: Экран выбора персонажа
   ├─ Создать персонажа (если < 2 персонажей)
   ├─ Загрузить персонажа (список существующих)
   └─ Отключиться (вернуться в главное меню)
5. После выбора → Спавн в мире
```

**База данных:**
```sql
-- Таблица игровых персонажей (отдельно от accounts!)
CREATE TABLE game_characters (
    uuid TEXT PRIMARY KEY,
    account_uuid TEXT,              -- Ссылка на accounts.uuid
    character_name TEXT UNIQUE,     -- Имя персонажа в мире
    created_at TIMESTAMP,
    last_played TIMESTAMP,

    -- Раса и пол
    race TEXT,                      -- human, elf, dwarf, halfling, orc, tiefling
    gender TEXT,                    -- male, female

    -- Фракция
    faction_id TEXT,                -- Ссылка на factions

    -- Модель персонажа
    model TEXT,                     -- human_male, elf_female, dwarf_male, etc. (race + gender)

    -- Позиция в мире
    pos_x REAL, pos_y REAL, pos_z REAL,

    -- D&D характеристики
    level INTEGER DEFAULT 1,
    experience INTEGER DEFAULT 0,
    class TEXT,                     -- fighter, wizard, rogue, cleric, ranger, barbarian, paladin, monk, druid, warlock, bard, sorcerer

    -- Базовые характеристики (основные)
    strength INTEGER,
    dexterity INTEGER,
    constitution INTEGER,
    intelligence INTEGER,
    wisdom INTEGER,
    charisma INTEGER,

    -- Вторичные характеристики
    hp_current INTEGER,
    hp_max INTEGER,
    armor_class INTEGER,
    proficiency_bonus INTEGER DEFAULT 2,

    -- Навыки и владения (JSON)
    skills TEXT,                    -- {"Athletics": true, "Stealth": true, ...}
    proficiencies TEXT,             -- {"weapons": ["simple", "martial"], "armor": ["light", "medium", "heavy", "shields"], "tools": ["gaming_set"], "saving_throws": ["STR", "CON"], "languages": ["Common", "Elvish"]}

    -- Предыстория (Background)
    background TEXT,                -- soldier, acolyte, criminal, folk_hero, noble, sage, charlatan
    background_feature TEXT,        -- military_rank, sanctuary, criminal_contact, etc.

    -- Классовые особенности (JSON)
    class_features TEXT,            -- {"fighting_style": "defense", "second_wind_uses": 1, ...}

    -- Черты характера (JSON)
    personality TEXT,               -- {"traits": ["..."], "ideals": "...", "bonds": "...", "flaws": "..."}

    -- Физическое описание (JSON)
    physical_description TEXT,      -- {"age": 27, "height": "6'2\"", "weight": 180, "eyes": "grey", "distinguishing_marks": "..."}

    -- Биография
    backstory TEXT,                 -- Текстовое описание биографии персонажа
    motivation TEXT,                -- wealth, protection, knowledge, revenge, redemption

    -- Инвентарь и экипировка (JSON)
    inventory TEXT,                 -- JSON массив предметов
    equipped TEXT,                  -- JSON экипированных слотов
    gold INTEGER DEFAULT 10,        -- Стартовое золото

    -- Заклинания (JSON)
    spells_known TEXT,              -- ["magic_missile", "fireball", ...]
    spell_slots TEXT,               -- {"1": {"total": 4, "used": 1}, "2": {"total": 3, "used": 0}, ...}

    FOREIGN KEY (account_uuid) REFERENCES accounts(uuid),
    CHECK ((SELECT COUNT(*) FROM game_characters WHERE account_uuid = account_uuid) <= 2)
);

-- Таблица фракций
CREATE TABLE factions (
    id TEXT PRIMARY KEY,
    name TEXT,                      -- Название фракции
    description TEXT,               -- Описание
    spawn_points TEXT,              -- JSON массив точек спавна [[x,y,z], ...]
    color TEXT,                     -- Цвет фракции в UI (hex: "#FF5733")

    -- Репутация с другими фракциями (JSON)
    relations TEXT                  -- {"faction_id": relation_value, ...}
);
```

**UI Компоненты:**

#### B. Система моделей персонажей

**Цель:** Простая система выбора готовых моделей персонажей без сложного редактора.

**Принцип:** По **2 готовые модели на каждую расу** (мужская и женская) + команда для администраторов.

**Доступные модели:**

| Раса | Мужская модель | Женская модель |
|------|----------------|----------------|
| Human | `human_male` | `human_female` |
| Elf | `elf_male` | `elf_female` |
| Dwarf | `dwarf_male` | `dwarf_female` |
| Halfling | `halfling_male` | `halfling_female` |
| Orc | `orc_male` | `orc_female` |
| Tiefling | `tiefling_male` | `tiefling_female` |

**Административная команда:**
```
/charsetmodel <название_модели>  — изменить модель персонажа (только для администраторов)

Примеры:
/charsetmodel elf_male           — установить модель мужчины-эльфа
/charsetmodel orc_female         — установить модель женщины-орка
```

**Технические требования:**

- **Единый риг** для всех рас/полов (возможно с незначительными модификациями)
- **Наследование анимаций** — все анимации применяются к любой модели с нужным ригом
- **Vertex Groups** для весов костей

**Примечание:** Расширенная система кастомизации внешности (причёски, бороды, цвет кожи и т.д.) описана в `docs/CHARACTER_CUSTOMIZATION.md` и может быть реализована в будущем.

**Правила распределения характеристик D&D 5e:**

**1. Point Buy (Покупка очков) — рекомендуется для баланса**

Стартовый бюджет: **27 очков**

Таблица стоимости характеристик:
| Значение | Стоимость | Модификатор |
|----------|-----------|-------------|
| 8        | 0         | -1          |
| 9        | 1         | -1          |
| 10       | 2         | +0          |
| 11       | 3         | +0          |
| 12       | 4         | +1          |
| 13       | 5         | +1          |
| 14       | 7         | +2          |
| 15       | 9         | +2          |

**Ограничения:**
- Минимум: 8
- Максимум: 15 (до расовых бонусов)
- После расовых бонусов максимум может быть 17

**Пример:**
```
STR: 15 (9 очков)
DEX: 14 (7 очков)
CON: 13 (5 очков)
INT: 10 (2 очков)
WIS: 12 (4 очков)
CHA: 8  (0 очков)
ИТОГО: 27 очков
```

**2. Standard Array (Стандартный набор) — быстро**

Игрок распределяет фиксированный набор значений: **[15, 14, 13, 12, 10, 8]**

Пример:
```
STR: 15  → с расовым бонусом Human (+1) = 16
DEX: 14  → 15
CON: 13  → 14
INT: 12  → 13
WIS: 10  → 11
CHA: 8   → 9
```

**3. Roll 4d6 (Броски кубов) — случайно**

Для каждой характеристики:
- Бросить 4d6
- Убрать наименьший результат
- Сумма оставшихся трёх = значение характеристики
- Повторить 6 раз

**В игре:** Сервер генерирует 6 случайных значений и отправляет клиенту. Игрок распределяет их по характеристикам.

**Расчёт модификаторов:**
```
Модификатор = (Характеристика - 10) / 2 (округление вниз)

Примеры:
8  → -1
10 → +0
12 → +1
14 → +2
16 → +3
18 → +4
20 → +5
```

**Расовые бонусы к характеристикам:**

| Раса     | Бонусы                    |
|----------|---------------------------|
| Human    | +1 ко всем характеристикам|
| Elf      | +2 DEX, +1 INT            |
| Dwarf    | +2 CON, +1 WIS            |
| Halfling | +2 DEX, +1 CHA            |
| Orc      | +2 STR, +1 CON            |
| Tiefling | +2 CHA, +1 INT            |

**Вторичные характеристики при создании:**

**Hit Points (HP):**
- HP = Hit Die + CON модификатор
- Hit Die зависит от класса:
  - Fighter, Paladin, Ranger: d10 (10 HP базовых)
  - Barbarian: d12 (12 HP)
  - Wizard, Sorcerer: d6 (6 HP)
  - Rogue, Monk, Bard, Warlock: d8 (8 HP)
  - Cleric, Druid: d8 (8 HP)

**Armor Class (AC):**
- AC = 10 + DEX модификатор (без брони)
- С бронёй: зависит от типа брони

**Профициency Bonus:**
- Уровень 1-4: +2
- Уровень 5-8: +3
- Уровень 9-12: +4
- Уровень 13-16: +5
- Уровень 17-20: +6

**Навыки (Skills):**

Каждый класс даёт выбор из **2-4 навыков** при создании персонажа.

**Список всех навыков D&D:**
- **STR:** Athletics
- **DEX:** Acrobatics, Sleight of Hand, Stealth

- **WIS:** Animal Handling, Insight, Medicine, Perception, Survival

#### C. Система NPC (ECS-архитектура)

**ВАЖНО:** NPC система должна быть реализована **ДО** системы фракций и отношений, так как фракции и отношения зависят от NPC.

**Цель:** Создать гибкую систему NPC на основе Entity-Component-System (ECS) архитектуры, аналогичной системе предметов.

##### Архитектурный подход: ECS

Вместо монолитного класса NPC используем компонентный подход, где каждый NPC — это Entity с набором компонентов:

```python
# Пример структуры NPC как Entity с компонентами
npc_entity = Entity(uuid="npc-001")
npc_entity.add_component(PositionComponent(x=10, y=5, z=1))
npc_entity.add_component(ModelComponent(model="human_male", animations=["idle", "walk"]))
npc_entity.add_component(AIComponent(behavior="patrol", aggro_radius=10))
npc_entity.add_component(DialogueComponent(dialogue_id="innkeeper_greeting"))
npc_entity.add_component(CombatComponent(hp=30, ac=12, attacks=["shortsword"]))
npc_entity.add_component(FactionComponent(faction_id="neutral", disposition=0))
npc_entity.add_component(PathfindingComponent(navmesh_agent=True))
npc_entity.add_component(InteractionComponent(interactions=["talk", "trade"]))
```

```python
# В AISystem
def _update_patrol(self, entity: Entity, dt: float):
    ai = entity.get_component(AIComponent)
    pathfinding = entity.get_component(PathfindingComponent)
    position = entity.get_component(PositionComponent)

    # Если достигли точки патрулирования — переход к следующей
    if position.distance_to(ai.patrol_points[ai.current_point]) < 0.5:
        ai.current_point = (ai.current_point + 1) % len(ai.patrol_points)
        pathfinding.target_pos = ai.patrol_points[ai.current_point]
        pathfinding.needs_repath = True
```

#### D. Система фракций

**Цель:** Разделение игроков по группам с уникальными точками спавна и отношениями.

**Базовые фракции:**

| ID | Название | Описание | Цвет |
|----|----------|----------|------|
| `alliance` | Альянс | Объединение людей и эльфов | `#0066CC` (синий) |
| `horde` | Орда | Орки и гоблины | `#CC0000` (красный) |
| `neutral` | Нейтралы | Торговцы и искатели приключений | `#CCCC00` (жёлтый) |
| `undead` | Нежить | Проклятые существа | `#6600CC` (фиолетовый) |

**Механики фракций:**

1. **Spawn points:**
   - Каждая фракция имеет свои точки спавна
   - При создании персонажа — спавн в столице фракции
   - При смерти — респавн в ближайшей точке фракции

2. **Отношения:**

#### B. Система бросков кубов (dnd_dice)

**Реализация:**

   ```python
   def roll_dice(notation: str) -> dict:
       # "1d20+5" -> {result: 18, rolls: [13], modifier: 5}

       # "2d8+3" -> {result: 14, rolls: [6, 5], modifier: 3}
   ```

#### C. Пошаговая боевая система (dnd_combat)

**Цель:** Turn-based бой с инициативой, действиями и реакциями

**Плагины:**
- `dnd_combat/sv_combat.py` — логика боя, инициатива, действия
- `dnd_combat/cl_combat_ui.py` — UI боевого режима
- `dnd_combat/cl_initiative.py` — трекер инициативы

**Реализация:**
1. **Боевые состояния:**
   ```python
   class CombatState:
       IN_COMBAT = 1      # Активный бой
       OUT_OF_COMBAT = 0  # Обычный режим
   ```

2. **Инициатива:**
   - DM начинает бой командой `/combat start`
   - Все участники бросают инициативу (d20 + DEX модификатор)
   - Порядок ходов отображается в UI

3. **Структура хода:**
   - **Движение** — до movement_speed футов (30 для большинства рас)
   - **Действие (Action)** — атака, заклинание, использование предмета
   - **Бонусное действие (Bonus Action)** — специальные способности
   - **Реакция (Reaction)** — opportunity attacks, counterspell

4. **UI боевого режима:**
   - Панель инициативы слева (список участников с HP)
   - Подсветка текущего хода
   - Кнопки действий: Attack / Cast Spell / Dash / Dodge / Help
   - Таймер хода (опционально)

5. **Сетевые сообщения:**
   ```json
   {"type": "combat_start"}
   {"type": "combat_initiative", "rolls": {"player1": 18, "goblin1": 12}}
   {"type": "combat_turn_start", "entity_uuid": "player1"}
   {"type": "combat_action", "action": "attack", "target": "goblin1"}
   {"type": "combat_end"}
   ```

6. **Ограничения движения:**
   - В режиме боя движение ограничено movement_speed
   - Визуализация области движения (круг радиусом 30 футов)
   - Перемещение за пределы области тратит Action на Dash

**Приоритет:** Критический — основная механика D&D

### Система потребностей (Needs System)

Каждый NPC имеет набор базовых потребностей, влияющих на поведение:

```python
@dataclass
class NeedsComponent(Component):
    """Потребности NPC (0-100, ниже = хуже)."""
    hunger: float = 100.0       # Голод (падает со временем)
    rest: float = 100.0         # Усталость (падает при активности)
    social: float = 100.0       # Социализация (падает в одиночестве)
    safety: float = 100.0       # Безопасность (падает при угрозах)
    comfort: float = 100.0      # Комфорт (зависит от окружения)
    purpose: float = 100.0      # Цель/смысл (падает при бездействии)

    # Пороговые значения
    CRITICAL = 20.0  # Критический уровень
    LOW = 40.0       # Низкий уровень
    NORMAL = 60.0    # Нормальный уровень
```

**Поведение при низких потребностях:**

| Потребность | Низкий уровень | Критический уровень |
|-------------|----------------|---------------------|
| Hunger | Ищет еду, становится раздражительным | Крадёт еду, теряет здоровье |
| Rest | Медленнее работает, ошибается | Засыпает где угодно |
| Social | Ищет компанию, грустит | Депрессия, уход в себя |
| Safety | Избегает опасных мест | Паника, бегство |
| Comfort | Жалуется, снижается мораль | Ищет лучшее место жительства |
| Purpose | Скучает, теряет мотивацию | Уходит искать приключения |

### Черты характера (Traits System)

Черты влияют на скорость изменения потребностей и реакции на события:

```python
class TraitType(Enum):
    # Социальные
    EXTROVERT = auto()      # +50% к падению social при одиночестве, +20% к восстановлению
    INTROVERT = auto()      # -30% к падению social, но медленнее восстанавливается
    CHARISMATIC = auto()    # +30% к влиянию на других NPC
    SOCIALLY_AWKWARD = auto()  # -20% к социальным взаимодействиям

    # Рабочие
    HARD_WORKER = auto()    # +25% к скорости работы, -10% rest
    LAZY = auto()           # -25% к работе, +15% rest
    PERFECTIONIST = auto()  # +качество работы, -скорость
    SLOPPY = auto()         # +скорость, -качество

    # Боевые
    BRAVE = auto()          # +50% safety в опасности
    COWARD = auto()         # -30% safety, бежит раньше
    BLOODTHIRSTY = auto()   # +combat mood, любит насилие
    PACIFIST = auto()       # -mood от насилия

    # Моральные
    KIND = auto()           # +social от помощи другим
    CRUEL = auto()          # +mood от чужих страданий
    HONEST = auto()         # Не лжёт, +trust от других
    DECEITFUL = auto()      # Может лгать, манипулировать

    # Особенности
```

### AI Decision Making (Дерево решений)

```python
class NPCBrain:
    """Мозг NPC — принимает решения на основе всех факторов."""

    def decide_action(self, npc: Entity) -> Action:
        needs = npc.get_component(NeedsComponent)
        traits = npc.get_component(TraitsComponent)
        relationships = npc.get_component(RelationshipComponent)
        profession = npc.get_component(ProfessionComponent)

        # 1. Срочные потребности (survival)
        if needs.hunger < needs.CRITICAL:
            return self._decide_food_action(npc)
        if needs.safety < needs.LOW:
            return self._decide_safety_action(npc)
        if needs.rest < needs.CRITICAL:
            return Action.SLEEP

        # 2. Социальные потребности
        if needs.social < needs.LOW:
            return self._decide_social_action(npc, relationships)

        # 3. Рабочее время?
        if self.is_work_time() and profession:
            return self._decide_work_action(npc, profession)

        # 4. Досуг
        return self._decide_leisure_action(npc, traits)

    def _decide_food_action(self, npc: Entity) -> Action:
        """Решает, как NPC будет добывать еду."""
        inventory = npc.get_component(InventoryComponent)
        traits = npc.get_component(TraitsComponent)

        # Есть еда в инвентаре?
        if inventory.has_food():
            return Action.EAT

        # Есть деньги? Идём в таверну
        if inventory.gold >= 2:
            return Action.GO_TO_TAVERN

        # Есть работа? Идём работать за еду
        profession = npc.get_component(ProfessionComponent)
        if profession and profession.workplace_id:
            return Action.WORK_FOR_FOOD

        # Черты влияют на выбор
        if TraitType.HONEST in traits.traits:
            return Action.BEG  # Просить милостыню
        elif TraitType.DECEITFUL in traits.traits:
            return Action.STEAL_FOOD  # Украсть
        else:
            # 50/50
            return random.choice([Action.BEG, Action.STEAL_FOOD])
```

```python
    location: Tuple[float, float, float]

    emotional_impact: int    # -100 до +100
```
