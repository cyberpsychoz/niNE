# D&D Режим (Отдельная ветка)

**ВАЖНО:** D&D режим — это **отдельная ветка разработки**, не влияющая на основное развитие niNE. Основной проект niNE продолжит развиваться независимо.

**Цель:** Создать специализированный режим для онлайн-сессий D&D с пошаговой боевой системой, расширенным управлением персонажами и инструментами для Игрового Мастера.

**Статус:** Отдельная ветка на основе стабильной версии **niNE 0.1.0-alpha**

**Принцип разработки:** Изменения **ТОЛЬКО в плагинах** (`nine/plugins/dnd/`). Ядро niNE остаётся неизменным, что позволяет:
- Легко мерджить обновления из основной ветки
- Не ломать базовый функционал niNE
- Использовать D&D режим как опциональное расширение

### Архитектура D&D режима

D&D режим реализуется исключительно через систему плагинов:

- **Плагины server-side:** Логика боевой системы, управление инициативой, броски кубов
- **Плагины client-side:** UI для листа персонажа, отображение боевого режима, инструменты DM
- **Плагины common:** Общие константы D&D (классы, расы, заклинания)

**Никаких изменений в core-модулях niNE!** Вся функциональность D&D добавляется через события и плагины.

### Фаза 0: Система персонажей и кастомизации (Приоритет: КРИТИЧЕСКИЙ)

**ВАЖНО:** Эта фаза должна быть реализована **ДО** всех остальных D&D механик, так как она является фундаментом для игрового опыта.

#### A. Экран выбора/создания персонажа

**Цель:** При входе в игру после авторизации показывать меню управления персонажами вместо немедленного спавна.

**Поток авторизации:**
```
1. Main Menu → Login
2. Успешная авторизация (auth/dev_auth)
3. ❌ СТАРОЕ: Сразу спавн в мире
4. ✅ НОВОЕ: Экран выбора персонажа
   ├─ Создать персонажа (если < 2 персонажей)
   ├─ Загрузить персонажа (список существующих)
   └─ Отключиться (вернуться в главное меню)
5. После выбора → Спавн в мире
```

**База данных:**
```sql
-- Таблица игровых персонажей (отдельно от accounts!)
CREATE TABLE game_characters (
    uuid TEXT PRIMARY KEY,
    account_uuid TEXT,              -- Ссылка на accounts.uuid
    character_name TEXT UNIQUE,     -- Имя персонажа в мире
    created_at TIMESTAMP,
    last_played TIMESTAMP,

    -- Раса и пол
    race TEXT,                      -- human, elf, dwarf, halfling, orc, tiefling
    gender TEXT,                    -- male, female

    -- Фракция
    faction_id TEXT,                -- Ссылка на factions

    -- Модель персонажа
    model TEXT,                     -- human_male, elf_female, dwarf_male, etc. (race + gender)

    -- Позиция в мире
    pos_x REAL, pos_y REAL, pos_z REAL,

    -- D&D характеристики
    level INTEGER DEFAULT 1,
    experience INTEGER DEFAULT 0,
    class TEXT,                     -- fighter, wizard, rogue, cleric, ranger, barbarian, paladin, monk, druid, warlock, bard, sorcerer

    -- Базовые характеристики (основные)
    strength INTEGER,
    dexterity INTEGER,
    constitution INTEGER,
    intelligence INTEGER,
    wisdom INTEGER,
    charisma INTEGER,

    -- Вторичные характеристики
    hp_current INTEGER,
    hp_max INTEGER,
    armor_class INTEGER,
    proficiency_bonus INTEGER DEFAULT 2,

    -- Навыки и владения (JSON)
    skills TEXT,                    -- {"Athletics": true, "Stealth": true, ...}
    proficiencies TEXT,             -- {"weapons": ["simple", "martial"], "armor": ["light", "medium", "heavy", "shields"], "tools": ["gaming_set"], "saving_throws": ["STR", "CON"], "languages": ["Common", "Elvish"]}

    -- Предыстория (Background)
    background TEXT,                -- soldier, acolyte, criminal, folk_hero, noble, sage, charlatan
    background_feature TEXT,        -- military_rank, sanctuary, criminal_contact, etc.

    -- Классовые особенности (JSON)
    class_features TEXT,            -- {"fighting_style": "defense", "second_wind_uses": 1, ...}

    -- Черты характера (JSON)
    personality TEXT,               -- {"traits": ["..."], "ideals": "...", "bonds": "...", "flaws": "..."}

    -- Физическое описание (JSON)
    physical_description TEXT,      -- {"age": 27, "height": "6'2\"", "weight": 180, "eyes": "grey", "distinguishing_marks": "..."}

    -- Биография
    backstory TEXT,                 -- Текстовое описание биографии персонажа
    motivation TEXT,                -- wealth, protection, knowledge, revenge, redemption

    -- Инвентарь и экипировка (JSON)
    inventory TEXT,                 -- JSON массив предметов
    equipped TEXT,                  -- JSON экипированных слотов
    gold INTEGER DEFAULT 10,        -- Стартовое золото

    -- Заклинания (JSON)
    spells_known TEXT,              -- ["magic_missile", "fireball", ...]
    spell_slots TEXT,               -- {"1": {"total": 4, "used": 1}, "2": {"total": 3, "used": 0}, ...}

    FOREIGN KEY (account_uuid) REFERENCES accounts(uuid),
    CHECK ((SELECT COUNT(*) FROM game_characters WHERE account_uuid = account_uuid) <= 2)
);

-- Таблица фракций
CREATE TABLE factions (
    id TEXT PRIMARY KEY,
    name TEXT,                      -- Название фракции
    description TEXT,               -- Описание
    spawn_points TEXT,              -- JSON массив точек спавна [[x,y,z], ...]
    color TEXT,                     -- Цвет фракции в UI (hex: "#FF5733")

    -- Репутация с другими фракциями (JSON)
    relations TEXT                  -- {"faction_id": relation_value, ...}
);
```

**UI Компоненты:**
- `cl_character_select_menu.py` — экран выбора/загрузки персонажа

#### B. Система моделей персонажей

**Цель:** Простая система выбора готовых моделей персонажей без сложного редактора.

**Принцип:** По **2 готовые модели на каждую расу** (мужская и женская) + команда для администраторов.

**Доступные модели:**

| Раса | Мужская модель | Женская модель |
|------|----------------|----------------|
| Human | `human_male` | `human_female` |
| Elf | `elf_male` | `elf_female` |
| Dwarf | `dwarf_male` | `dwarf_female` |
| Halfling | `halfling_male` | `halfling_female` |
| Orc | `orc_male` | `orc_female` |
| Tiefling | `tiefling_male` | `tiefling_female` |

**Административная команда:**
```
/charsetmodel <название_модели>  — изменить модель персонажа (только для администраторов)

Примеры:
/charsetmodel elf_male           — установить модель мужчины-эльфа
/charsetmodel orc_female         — установить модель женщины-орка
```

**Технические требования:**

- **Единый риг** для всех рас/полов (возможно с незначительными модификациями)
- **Наследование анимаций** — все анимации применяются к любой модели с нужным ригом
- **Vertex Groups** для весов костей

**Примечание:** Расширенная система кастомизации внешности (причёски, бороды, цвет кожи и т.д.) описана в `docs/CHARACTER_CUSTOMIZATION.md` и может быть реализована в будущем.


**Правила распределения характеристик D&D 5e:**

**1. Point Buy (Покупка очков) — рекомендуется для баланса**

Стартовый бюджет: **27 очков**

Таблица стоимости характеристик:
| Значение | Стоимость | Модификатор |
|----------|-----------|-------------|
| 8        | 0         | -1          |
| 9        | 1         | -1          |
| 10       | 2         | +0          |
| 11       | 3         | +0          |
| 12       | 4         | +1          |
| 13       | 5         | +1          |
| 14       | 7         | +2          |
| 15       | 9         | +2          |

**Ограничения:**
- Минимум: 8
- Максимум: 15 (до расовых бонусов)
- После расовых бонусов максимум может быть 17

**Пример:**
```
STR: 15 (9 очков)
DEX: 14 (7 очков)
CON: 13 (5 очков)
INT: 10 (2 очков)
WIS: 12 (4 очков)
CHA: 8  (0 очков)
ИТОГО: 27 очков
```

**2. Standard Array (Стандартный набор) — быстро**

Игрок распределяет фиксированный набор значений: **[15, 14, 13, 12, 10, 8]**

Пример:
```
STR: 15  → с расовым бонусом Human (+1) = 16
DEX: 14  → 15
CON: 13  → 14
INT: 12  → 13
WIS: 10  → 11
CHA: 8   → 9
```

**3. Roll 4d6 (Броски кубов) — случайно**

Для каждой характеристики:
- Бросить 4d6
- Убрать наименьший результат
- Сумма оставшихся трёх = значение характеристики
- Повторить 6 раз

**В игре:** Сервер генерирует 6 случайных значений и отправляет клиенту. Игрок распределяет их по характеристикам.

**Расчёт модификаторов:**
```
Модификатор = (Характеристика - 10) / 2 (округление вниз)

Примеры:
8  → -1
10 → +0
12 → +1
14 → +2
16 → +3
18 → +4
20 → +5
```

**Расовые бонусы к характеристикам:**

| Раса     | Бонусы                    |
|----------|---------------------------|
| Human    | +1 ко всем характеристикам|
| Elf      | +2 DEX, +1 INT            |
| Dwarf    | +2 CON, +1 WIS            |
| Halfling | +2 DEX, +1 CHA            |
| Orc      | +2 STR, +1 CON            |
| Tiefling | +2 CHA, +1 INT            |

**Вторичные характеристики при создании:**

**Hit Points (HP):**
- HP = Hit Die + CON модификатор
- Hit Die зависит от класса:
  - Fighter, Paladin, Ranger: d10 (10 HP базовых)
  - Barbarian: d12 (12 HP)
  - Wizard, Sorcerer: d6 (6 HP)
  - Rogue, Monk, Bard, Warlock: d8 (8 HP)
  - Cleric, Druid: d8 (8 HP)

**Armor Class (AC):**
- AC = 10 + DEX модификатор (без брони)
- С бронёй: зависит от типа брони

**Профициency Bonus:**
- Уровень 1-4: +2
- Уровень 5-8: +3
- Уровень 9-12: +4
- Уровень 13-16: +5
- Уровень 17-20: +6

**Навыки (Skills):**

Каждый класс даёт выбор из **2-4 навыков** при создании персонажа.

**Список всех навыков D&D:**
- **STR:** Athletics
- **DEX:** Acrobatics, Sleight of Hand, Stealth
- **INT:** Arcana, History, Investigation, Nature, Religion
- **WIS:** Animal Handling, Insight, Medicine, Perception, Survival
- **CHA:** Deception, Intimidation, Performance, Persuasion

**Примеры выбора навыков по классам:**
- **Fighter:** Выбрать 2 из {Acrobatics, Animal Handling, Athletics, History, Insight, Intimidation, Perception, Survival}
- **Wizard:** Выбрать 2 из {Arcana, History, Insight, Investigation, Medicine, Religion}
- **Rogue:** Выбрать 4 из {Acrobatics, Athletics, Deception, Insight, Intimidation, Investigation, Perception, Performance, Persuasion, Sleight of Hand, Stealth}

**Владения (Proficiencies):**

При создании персонажа автоматически назначаются владения на основе класса:

**Fighter:**
- Оружие: Все простое и воинское оружие
- Броня: Вся броня, щиты
- Спасброски: STR, CON

**Wizard:**
- Оружие: Кинжалы, дротики, пращи, боевые посохи, лёгкие арбалеты
- Броня: Нет
- Спасброски: INT, WIS

**Rogue:**
- Оружие: Простое оружие, ручные арбалеты, длинные мечи, рапиры, короткие мечи
- Броня: Лёгкая броня
- Инструменты: Воровские инструменты
- Спасброски: DEX, INT

*(Полный список для всех классов будет в `dnd/common/data/classes.json`)*

**Резюме системы создания персонажа:**

Игрок проходит **полноценный процесс создания D&D персонажа** в 7 шагов, заполняя виртуальный лист персонажа:

1. ✅ **Раса и пол** — выбор расы (с расовыми особенностями) и пола (автоматический выбор модели)
2. ✅ **Класс** — выбор класса с описанием всех способностей 1 уровня
3. ✅ **Характеристики** — распределение 6 характеристик (Point Buy/Standard Array/Roll 4d6) с расчётом модификаторов
4. ✅ **Навыки и владения** — выбор навыков согласно классу, автоматическое назначение владений (оружие, броня, спасброски, языки)
5. ✅ **Предыстория (Background)** — выбор background (Soldier, Criminal, Acolyte...) с дополнительными навыками и особенностями
6. ✅ **Особенности и черты** — выбор классовых особенностей (Fighting Style), черт характера (Personality Traits, Ideals, Bonds, Flaws)
7. ✅ **Биография и описание** — имя, фракция, возраст, рост, вес, цвет глаз, отличительные черты, биография, мотивация
8. ✅ **Финальное подтверждение** — полный чарлист с превью персонажа

**Итого:** Игрок получает **полноценного D&D персонажа** с заполненным листом персонажа, готового к игре.

**Примечание:** Администраторы могут изменить модель любого персонажа командой `/charsetmodel <название_модели>`.

#### C. Система фракций

**Цель:** Разделение игроков по группам с уникальными точками спавна и отношениями.

**Базовые фракции:**

| ID | Название | Описание | Цвет |
|----|----------|----------|------|
| `alliance` | Альянс | Объединение людей и эльфов | `#0066CC` (синий) |
| `horde` | Орда | Орки и гоблины | `#CC0000` (красный) |
| `neutral` | Нейтралы | Торговцы и искатели приключений | `#CCCC00` (жёлтый) |
| `undead` | Нежить | Проклятые существа | `#6600CC` (фиолетовый) |

**Механики фракций:**

1. **Spawn points:**
   - Каждая фракция имеет свои точки спавна
   - При создании персонажа — спавн в столице фракции
   - При смерти — респавн в ближайшей точке фракции

2. **Отношения:**
   ```json
   {
     "alliance": {
       "alliance": 100,    // Союзники
       "horde": -100,      // Враги
       "neutral": 0,       // Нейтральные
       "undead": -50       // Напряжённые
     }
   }
   ```

3. **PvP правила (опционально):**
   - Враждебные фракции могут атаковать друг друга
   - Нейтральные зоны (города) — PvP запрещён
   - DM может изменять отношения между фракциями

4. **UI индикация:**
   - Цвет ника игрока соответствует его фракции
   - Иконка фракции в листе персонажа

**Плагины:**
- `dnd_factions/sv_factions.py` — логика фракций
- `dnd_factions/cl_faction_ui.py` — отображение фракций в UI
- `dnd_factions/data/factions.json` — конфигурация фракций

#### C. Пошаговая боевая система (dnd_combat)

**Цель:** Turn-based бой с инициативой, действиями и реакциями

**Плагины:**
- `dnd_combat/sv_combat.py` — логика боя, инициатива, действия

   ```python
   class CombatState:

   ```

2. **Инициатива:**
   - DM начинает бой командой `/combat start`

3. **Структура хода:**
   - **Движение** — до movement_speed футов (30 для большинства рас)

   ```json
   {"type": "combat_start"}

   ```

6. **Ограничения движения:**
   - В режиме боя движение ограничено movement_speed
   - Визуализация области движения (круг радиусом 30 футов)
   - Перемещение за пределы области тратит Action на Dash

**Плагины:**

- `dnd_dm/cl_dm_panel.py` — панель управления DM
- `dnd_dm/cl_dm_tools.py` — инструменты (спавн НПС, телепорт игроков)

**Реализация:**
1. **Права доступа:**
   ```python
   # В базе данных
   ALTER TABLE accounts ADD COLUMN role TEXT DEFAULT 'player';
   # Возможные роли: 'player', 'dm', 'admin'
   ```

2. **Режим невидимости:**
   - DM может переключаться в режим невидимости (клавиша F1)
   - В этом режиме DM не отображается для игроков
   - Свободное перемещение (noclip) без коллизий
   - Возможность наблюдать за игроками

3. **DM панель (F2):**
   - **Вкладка "Игроки":**
     - Список подключённых игроков
     - Телепорт к игроку / Телепорт игрока к себе
     - Просмотр листа персонажа
     - Изменение HP/условий

   - **Вкладка "Бой":**
     - Начать/закончить бой
     - Добавить/удалить участника
     - Изменить инициативу
     - Пропустить ход

   - **Вкладка "Спавн":**
     - Список доступных НПС/монстров
     - Спавн на курсоре
     - Спавн в координатах

   - **Вкладка "События":**
     - Триггеры событий (двери, ловушки)
     - Погодные эффекты
     - Звуки окружения

4. **DM команды:**
   ```
   /dm invisibility [on/off]   — невидимость
   /dm noclip [on/off]         — прохождение сквозь стены
   /dm tp <player> <x> <y> <z> — телепорт игрока
   /dm spawn <npc_id>          — спавн НПС
   /dm heal <player> [amount]  — восстановить HP
   /dm damage <player> <amount>— нанести урон
   /dm say <text>              — голос от имени рассказчика
   ```

5. **Быстрые действия:**
   - **ЛКМ по игроку** — контекстное меню (телепорт, просмотр характеристик, урон/хил)
   - **ПКМ на земле** — спавн последнего выбранного НПС
   - **Ctrl+клик** — телепорт к точке

**Приоритет:** Высокий — необходим для ведения сессий

#### C. Система НПС (dnd_npc)

**Цель:** НПС с диалогами, квестами и AI поведением

**Плагины:**
- `dnd_npc/sv_npc.py` — логика НПС, AI
- `dnd_npc/cl_npc_dialogue.py` — UI диалогов
- `dnd_npc/data/` — JSON файлы НПС и диалогов

**Реализация:**
1. **База данных НПС:**
   ```sql
   CREATE TABLE npc_templates (
       id TEXT PRIMARY KEY,
       name TEXT,
       model TEXT,           -- Путь к модели
       dialogue_id TEXT,     -- Ссылка на файл диалога
       stats TEXT,           -- JSON статов для боя
       loot_table TEXT,      -- JSON таблицы лута
       ai_behavior TEXT      -- hostile/neutral/friendly
   );

   CREATE TABLE npc_instances (
       uuid TEXT PRIMARY KEY,
       template_id TEXT,
       pos_x REAL, pos_y REAL, pos_z REAL,
       hp_current INTEGER,
       state TEXT            -- idle/patrol/combat/dead
   );
   ```

2. **Диалоги (JSON формат):**
   ```json
   {
     "id": "innkeeper_greeting",
     "nodes": [
       {
         "id": "start",
         "npc_text": "Добро пожаловать в таверну! Что желаете?",
         "choices": [
           {"text": "Мне нужна комната", "next": "rent_room"},
           {"text": "Есть ли работа?", "next": "quest_offer"},
           {"text": "Прощайте", "next": "end"}
         ]
       },
       {
         "id": "rent_room",
         "npc_text": "5 золотых за ночь.",
         "condition": {"gold": 5},
         "action": {"remove_gold": 5, "give_buff": "rested"},
         "next": "end"
       }
     ]
   }
   ```

3. **AI поведение:**
   - **Idle** — стоит на месте, может иметь патрульные точки
   - **Patrol** — ходит по заданному маршруту
   - **Combat** — атакует ближайшего врага в радиусе агро
   - **Flee** — убегает при низком HP
   - **Dead** — не двигается, можно лутать

4. **Интерактивность:**
   - **E** на НПС — открыть диалог / торговлю
   - **Клик на труп** — окно лута
   - **DM может управлять НПС** — говорить от их имени, двигать

**Приоритет:** Средний — нужен для квестов и окружения

**Начать с:**
1. Создать структуру папок `nine/plugins/dnd/`
