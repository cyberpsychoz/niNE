# Руководство по созданию кастомизируемых персонажей в Blender

**Цель:** Создать систему модульных low-poly персонажей для D&D режима с поддержкой кастомизации внешности и наследования анимаций.

**Целевой формат:** `.bam` (Panda3D)

**Инструменты:** Blender 3.x+, YABEE (Yet Another Blender Egg Exporter) или `blend2bam`

## 2. Создание единого рига (humanoid_rig)

### 2.1. Структура скелета

**ВАЖНО:** Все персонажи должны использовать **ОДИНАКОВЫЕ** названия костей!

**Рекомендуемая иерархия костей:**

```
Root
├── Hips (pelvis)
│   ├── Spine
│   │   ├── Spine1
│   │   │   ├── Spine2
│   │   │   │   ├── Neck
│   │   │   │   │   └── Head
│   │   │   │   │       ├── HeadEnd (optional)
│   │   │   │   │       └── Jaw (optional)
│   │   │   │   │
│   │   │   │   ├── Shoulder.L
│   │   │   │   │   └── UpperArm.L
│   │   │   │   │       └── Forearm.L
│   │   │   │   │           └── Hand.L
│   │   │   │   │               ├── Finger1.L ... Finger5.L
│   │   │   │   │
│   │   │   │   └── Shoulder.R
│   │   │   │       └── UpperArm.R
│   │   │   │           └── Forearm.R
│   │   │   │               └── Hand.R
│   │   │   │                   └── Finger1.R ... Finger5.R
│   │   │
│   ├── UpperLeg.L
│   │   └── LowerLeg.L
│   │       └── Foot.L
│   │           └── Toe.L
│   │
│   └── UpperLeg.R
│       └── LowerLeg.R
│           └── Foot.R
│               └── Toe.R
```

**Дополнительные кости для некоторых рас:**
- **Tiefling:** `Tail`, `Tail1`, `Tail2`, `Tail3`
- **Elf/Tiefling:** `Ear.L`, `Ear.R`
- **Рога (Tiefling):** `Horn.L`, `Horn.R`

### 2.2. Создание рига в Blender

1. **Создайте Armature:**
   - Add → Armature
   - Переключитесь в Edit Mode (`Tab`)
   - Создайте кости согласно иерархии выше

2. **Правила именования:**
   - Используйте `.L` и `.R` для симметричных костей (автоматическое зеркалирование)
   - Названия должны быть **точно как в списке** выше

3. **Настройка рига:**
   - **Root bone** должна быть на уровне земли (Z = 0)
   - **Hips** — на высоте таза (~1.0 unit для человека)
   - **Пропорции:** Стандартная гуманоидная пропорция (7-8 голов в высоту)

4. **IK Controllers (опционально):**
   - Для упрощения анимации можете добавить IK кости для рук и ног
   - **НО**: при экспорте экспортируйте только деформирующие кости!

5. **Экспорт рига:**
   - Выделите только Armature
   - Экспортируйте как `.bam` через `blend2bam` или YABEE

## 3. Создание базовых моделей рас

### 3.1. Принципы моделирования

**Low-poly требования:**
- **Целевой полигонаж:**
  - Голова: 200-400 треугольников
  - Торс: 300-500 треугольников
  - Руки: 150-250 треугольников (каждая)
  - Ноги: 200-350 треугольников (каждая)
  - **Итого:** ~1500-2500 треугольников на персонажа

**Топология:**
- **Edge loops** вокруг суставов (плечи, локти, колени, таз)
- **Минимальная геометрия** для лица (лицо будет текстурой!)
- **Flat shading** или **Smooth shading** — на ваш выбор

### 3.2. Модульная структура mesh

**КРИТИЧНО:** Персонаж должен состоять из **отдельных объектов** для каждой части тела:

```
HumanMale (Armature)
├── Head_Mesh           ← Отдельный объект
├── Torso_Mesh          ← Отдельный объект
├── UpperArm_L_Mesh     ← Отдельный объект
├── UpperArm_R_Mesh
├── Forearm_L_Mesh
├── Forearm_R_Mesh
├── Hand_L_Mesh
├── Hand_R_Mesh
├── UpperLeg_L_Mesh
├── UpperLeg_R_Mesh
├── LowerLeg_L_Mesh
├── LowerLeg_R_Mesh
├── Foot_L_Mesh
└── Foot_R_Mesh
```

**Зачем?**
- Можно заменять отдельные части (например, торс для разных телосложений)
- Легче управлять текстурами
- Проще кастомизация в коде

### 3.3. UV-развёртка

**Голова:**
- **Лицо** — отдельная UV-группа (передняя часть головы)
- **Затылок/уши** — отдельная UV-группа
- Разрешение текстуры: 512x512 или 1024x1024

**Тело:**
- Простая UV-развёртка
- Может использовать однотонную текстуру + vertex colors для цвета кожи

**Волосы/борода:**
- Отдельные UV-карты
- Используйте **vertex colors** для цвета волос (проще менять в коде)

### 3.4. Vertex Groups (Weight Painting)

**Каждая часть тела должна быть привязана к костям:**

1. Выберите mesh объект
2. Переключитесь в Weight Paint Mode
3. Назначьте веса для каждой кости:
   - **Head_Mesh** → 100% вес на кость `Head`
   - **Torso_Mesh** → веса на `Spine`, `Spine1`, `Spine2`
   - **UpperArm_L_Mesh** → веса на `Shoulder.L`, `UpperArm.L`
   - И так далее...

**Советы по weight painting:**
- Используйте **Automatic Weights** как стартовую точку (Ctrl+P → Armature Deform → With Automatic Weights)
- Вручную подправьте веса в проблемных зонах (суставы)
- **Плавные переходы** весов в местах сгибов (локти, колени)

## 4. Создание вариаций рас

### 4.1. Human (Человек) — базовая раса

- **Пропорции:** Стандартные (1.0x масштаб)
- **Рост:** ~1.75 units (male), ~1.65 units (female)
- **Особенности:** Нет

**Файлы:**
- `human_male_base.blend`
- `human_female_base.blend`

### 4.2. Elf (Эльф)

- **Изменения относительно Human:**
  - **Уши** — удлинённые, заострённые (+200-300 полигонов)
  - **Пропорции:** Более изящные, тонкие
  - **Рост:** Такой же как у людей или чуть выше

**Как создать:**
1. Дублируйте `human_base.blend`
2. Отредактируйте `Head_Mesh`:
   - Extrude уши, сделайте их длинными и острыми
3. Сделайте торс/конечности чуть тоньше (масштаб по X: 0.95)
4. Сохраните как `elf_male_base.blend`

### 4.3. Dwarf (Дварф)

- **Изменения:**
  - **Рост:** ~1.2-1.3 units (коренастый)
  - **Пропорции:** Широкие плечи, короткие ноги
  - **Масштаб:** Торс шире (1.2x), ноги короче (0.7x)

**Как создать:**
1. Дублируйте `human_base.blend`
2. **Масштабируйте кости ног:** 0.7x по Z
3. **Масштабируйте торс:** 1.2x по X и Y
4. Подправьте mesh под новые пропорции
5. Сохраните как `dwarf_male_base.blend`

### 4.4. Halfling (Полурослик)

- **Изменения:**
  - **Рост:** ~1.0 units
  - **Пропорции:** Детские (большая голова относительно тела)
  - **Масштаб:** 0.6x от человека

**Как создать:**
1. Возьмите `human_base.blend`
2. Масштабируйте весь скелет: 0.6x
3. Голову масштабируйте обратно: 1.3x (относительно нового размера)
4. Сохраните как `halfling_male_base.blend`

### 4.5. Orc (Орк)

- **Изменения:**
  - **Рост:** ~2.0 units (массивный)
  - **Пропорции:** Широкие плечи, мускулистый
  - **Кожа:** Зелёная (через vertex colors или текстуру)
  - **Лицо:** Клыки, грубые черты

**Как создать:**
1. Дублируйте `human_base.blend`
2. Масштабируйте скелет: 1.15x общий рост
3. Торс и руки: 1.3x по X/Y (массивнее)
4. Отредактируйте `Head_Mesh`:
   - Добавьте клыки (extrude из нижней челюсти)
   - Сделайте брови выступающими
5. **Цвет кожи:** Установите vertex color на зелёный (#4A7C59)
6. Сохраните как `orc_male_base.blend`

### 4.6. Tiefling (Тифлинг)

- **Изменения:**
  - **Рога** — два рога на голове (+300-500 полигонов)
  - **Хвост** — длинный хвост (+200-300 полигонов)
  - **Кожа:** Красноватая или фиолетовая
  - **Глаза:** Могут светиться (через emissive текстуру)

**Как создать:**
1. Дублируйте `human_base.blend`
2. **Добавьте рога к голове:**
   - Моделируйте как отдельный mesh или часть головы
   - Примерная форма: изогнутые назад рога (как у демона)
3. **Добавьте хвост:**
   - Создайте chain из 3-4 костей: `Tail`, `Tail1`, `Tail2`, `Tail3`
   - Присоедините к кости `Hips`
   - Смоделируйте тонкий изогнутый хвост
4. **Weight painting для хвоста:**
   - `Tail` mesh привяжите к костям хвоста с плавными переходами
5. **Цвет кожи:** Красноватый (#8B3A3A) или фиолетовый (#6A4C93)
6. Сохраните как `tiefling_male_base.blend`

## 5. Создание модульных причёсок

### 5.1. Принципы создания волос

**Стиль:** Low-poly "hair cards" (плоскости с текстурой волос) ИЛИ объёмное моделирование

**Рекомендуемый подход:** Объёмное low-poly моделирование

### 5.2. Создание причёски

1. **Откройте любой base файл** (например, `human_male_base.blend`)
2. **Создайте новый mesh объект** для волос
3. **Моделируйте причёску:**
   - Полигонаж: 300-800 треугольников
   - Волосы должны **плотно прилегать** к голове
   - Оставьте место для ушей (или скройте их для длинных причёсок)

4. **Именование:**
   - Назовите объект `Hair` (или `Hair_Style_01`)

5. **Weight painting:**
   - Привяжите волосы к кости `Head` (100% вес)

6. **Цвет волос:**
   - **Vertex colors:** Установите базовый цвет (коричневый #5C4033)
   - В игре цвет будет меняться через shader

7. **Экспорт:**
   - Удалите базовую модель головы (оставьте только Armature + Hair mesh)
   - Экспортируйте как `hair_style_01.bam`

### 5.3. Список причёсок (минимум)

**Male:**
1. **Short_01** — короткая стрижка
2. **Short_02** — военная стрижка (buzz cut)
3. **Medium_01** — средней длины, зачёсанные назад
4. **Medium_02** — растрёпанные
5. **Long_01** — длинные прямые
6. **Long_02** — длинные волнистые
7. **Ponytail** — хвост
8. **Bald** — лысый (пустой mesh или без волос вообще)

**Female:**
1. **Short_01** — короткая стрижка (пикси)
2. **Medium_01** — каре
3. **Medium_02** — до плеч, прямые
4. **Long_01** — длинные прямые
5. **Long_02** — длинные волнистые
6. **Ponytail** — высокий хвост
7. **Braids** — косы
8. **Bun** — пучок

## 6. Создание бород (только male)

### 6.1. Принципы

- **Низкий полигонаж:** 100-300 треугольников
- **Привязка:** К кости `Head` или `Jaw` (если есть)
- **Цвет:** Vertex colors (синхронизирован с цветом волос)

### 6.2. Список бород (минимум)

1. **None** — без бороды
2. **Stubble** — щетина (текстура на лице ИЛИ очень короткие полигоны)
3. **Goatee** — козлиная бородка
4. **Full_Short** — полная короткая борода
5. **Full_Long** — полная длинная борода
6. **Moustache** — только усы
7. **Braided** — заплетённая борода (для дварфов)

### 6.3. Создание бороды

1. Откройте `human_male_base.blend`
2. Создайте mesh для бороды
3. Моделируйте от подбородка вниз
4. Weight painting к кости `Head` или `Jaw`
5. Экспортируйте отдельно: `beard_style_01.bam`

## 7. Создание вариаций телосложения

### 7.1. Зачем нужны разные телосложения?

- **Slim (Худой):** Для ловких классов (Rogue, Ranger)
- **Normal (Нормальный):** Базовая модель
- **Muscular (Мускулистый):** Для силовых классов (Fighter, Barbarian)

### 7.2. Создание вариаций

**Способ 1: Shape Keys (проще)**

1. Откройте `human_male_base.blend`
2. Выберите `Torso_Mesh`
3. Создайте Shape Key:
   - Basis (базовая форма)
   - Muscular (увеличьте грудь, руки в 1.2x)
   - Slim (уменьшите торс до 0.85x)
4. **НО**: Экспорт Shape Keys в Panda3D требует доп. настройки

**Способ 2: Отдельные модели (рекомендуется)**

1. Создайте три копии торса:
   - `torso_slim.blend` — масштаб 0.85x
   - `torso_normal.blend` — базовый
   - `torso_muscular.blend` — масштаб 1.2x по X/Y
2. Экспортируйте отдельно
3. В игре подгружайте нужный торс динамически

## 9. Система наследования анимаций

### 9.1. Принцип работы

**Ключевая идея:** Все расы используют **одинаковый риг** → все анимации работают на всех моделях

**В Panda3D:**
```python
# Загружаем модель персонажа
character = loader.loadModel("races/elf/male_base.bam")

# Загружаем риг с анимациями
rig = loader.loadModel("rigs/humanoid_rig.bam")

# Применяем анимации к персонажу
character.reparentTo(rig)
rig.loop("walk")  # Анимация применяется к эльфу!
```

**ВАЖНО:** Для этого нужно, чтобы:
1. Названия костей были **идентичны** во всех моделях
2. Пропорции костей были **примерно одинаковы** (иначе будут артефакты)

### 9.2. Обработка различий в пропорциях

**Проблема:** Дварф в 2 раза ниже человека → анимация ходьбы будет странной

**Решение 1:** Масштабируйте весь риг при загрузке
```python
dwarf.setScale(0.6)  # Дварф меньше
```

**Решение 2:** Создайте отдельные анимации для рас с сильно отличающимися пропорциями
- Для Human, Elf, Orc — общие анимации
- Для Dwarf, Halfling — отдельный набор (с учётом коротких ног)

## 10. Список анимаций (обязательные)

### 10.1. Базовые анимации (приоритет: КРИТИЧЕСКИЙ)

## 11. Создание анимаций в Blender

### 11.1. Настройка сцены для анимации

1. **Откройте `humanoid_rig.blend`**
2. Установите FPS: 24 или 30 (Properties → Output → Frame Rate)
3. Создайте новую Action: Dope Sheet → Action Editor → New

### 11.2. Keyframe анимация

**Пример: Создание анимации ходьбы (walk)**

1. **Кадр 1:** Контактная поза
   - Левая нога впереди (касается земли)
   - Правая нога сзади (на носке)
   - Правая рука впереди, левая сзади (противоположно ногам)

2. **Кадр 12:** Passing pose
   - Ноги на одной линии
   - Тело чуть выше
   - Руки по бокам

3. **Кадр 24:** Контактная поза (зеркально)
   - Правая нога впереди
   - Левая нога сзади
   - Левая рука впереди

4. **Повторить цикл**

**Keyframe советы:**
- Используйте Graph Editor для сглаживания кривых
- **Root motion:** Кость `Root` должна двигаться вперёд (в коде это движение можно отключить и управлять позицией через скрипт)
- **Bounce:** Лёгкое вертикальное покачивание бёдер (Hips) при ходьбе

### 11.3. Именование Actions

**ВАЖНО:** Названия Actions должны совпадать с названиями из таблицы выше!

- `idle`
- `walk`
- `run`
- `attack_melee_1h`
- и т.д.

### 11.4. Экспорт анимаций

**Способ 1: Все анимации в одном файле**
- Сохраните все Actions в `animations.blend`
- Экспортируйте в `animations.bam`
- В Panda3D: `actor.loadAnims({"walk": "animations.bam"})`

**Способ 2: Отдельные файлы для каждой анимации**
- `walk.blend` → `walk.bam`
- `run.blend` → `run.bam`
- В Panda3D: `actor.loadAnims({"walk": "walk.bam", "run": "run.bam"})`

**Рекомендуется:** Способ 1 (проще управлять)

        ShowBase.__init__(self)

        # Загрузка персонажа с анимациями

            "models/races/human/male_base.bam",
            {
                "idle": "models/animations.bam",
                "walk": "models/animations.bam"

## 16. FAQ

**Q: Можно ли использовать один риг для всех рас?**
A: Да, если пропорции не слишком отличаются. Для Dwarf/Halfling может потребоваться отдельный риг из-за коротких ног.

**Q: Как лучше реализовать цвет кожи — текстурой или vertex colors?**
A: Vertex colors проще для динамической смены цвета в коде. Текстура даёт больше деталей. Рекомендуется: базовая текстура + vertex color tint.

**Q: Сколько времени займёт создание всех ассетов?**
A: Примерно:
- Риг: 2-3 часа
- Одна раса (male+female): 8-12 часов
- Одна анимация: 1-2 часа
- **Итого:** 100-150 часов работы для полного набора

**Q: Можно ли использовать готовые модели/анимации?**
A: Да, но убедитесь, что лицензия позволяет использование в вашем проекте. Mixamo, например, имеет бесплатные анимации (нужна регистрация).
