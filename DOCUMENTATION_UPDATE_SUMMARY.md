## Связи между проблемами (ключевые находки)

### БАГ #2 является корневой причиной множественных проблем:

```
БАГ #2: AISystem coupling с NPCManager
  │
  ├─→ NPC проблема #4: "Бой начинается автоматически"
  │   └─→ Причина: player_cache пуст без NPCManager
  │       └─→ AI не может корректно определить врагов
  │
  ├─→ AI поведение: "Гоблин атакует игрока"
  │   └─→ Заблокировано: NPC не видят игроков
  │
  └─→ AI поведение: "Страж реагирует на NPC"
      └─→ Заблокировано: NPC не видят игроков
```

### БАГ #1 блокирует тестирование:

```
БАГ #1: ECS Pending Addition
  │
  ├─→ Блокирует все unit-тесты ECS систем
  │   └─→ Entities не доступны сразу после создания
  │
  └─→ Может вызывать runtime баги
      └─→ При быстром создании/запросе entities
```
