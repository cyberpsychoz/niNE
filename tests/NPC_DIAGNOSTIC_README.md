# NPC Diagnostic Tool

Изолированная тестовая среда для диагностики NPC системы.

## Проблемы которые тестирует

1. **Рендеринг**: Применение цветов к NPC моделям
2. **Синхронизация**: Передача данных сервер → клиент
3. **Анимации**: T-поза vs правильные анимации
4. **Мигание**: Пропадание NPC при движении
5. **Боевая система**: Автоматическое начало боя
6. **Turn management**: Движение не в свой ход
7. **Видимость**: NPC невидимы при спавне

## Запуск

### Шаг 1: Запустить сервер
```bash
python -m nine.server.game_server
```

### Шаг 2: Запустить диагностический клиент
```bash
python -m tests.test_npc_diagnostic
```

### Шаг 3: Тестирование
1. Нажмите `1` - спавнит гоблина в позиции (0, 3, 0)
2. Проверьте консоль/лог на:
   - "NEW NPC SPAWNED" - подробная информация
   - "Model path from server: 'goblin'" - что пришло с сервера
   - "Applied color: (0.4, 0.6, 0.3, 1)" - цвет зелёный?
3. Проверьте визуально:
   - NPC виден сразу?
   - Цвет зелёный (не синий)?
   - T-поза или анимация idle?
   - Мигает при движении?

4. Нажмите `2` - начать бой
5. Проверьте:
   - Бой начался автоматически или только по команде?
   - Можно ли двигаться не в свой ход?
   - У гоблина бесконечный ход?

## Логи

Проверьте оба лог-файла:
- `npc_diagnostic.log` - диагностический клиент (DEBUG уровень)
- `server.log` - сервер (INFO уровень)

## Ожидаемые результаты

### Правильное поведение:
```
=== NEW NPC SPAWNED ===
Entity ID: npc_abc123
Display name: Гоблин
Model: goblin
Position: {'x': 0, 'y': 3, 'z': 0}
HP: 7/7
AI State: IDLE

Model path from server: 'goblin'
NPC type for color mapping: 'goblin'
Applied color: (0.4, 0.6, 0.3, 1)
NPC visual created successfully
```

### Проблемное поведение:
- Model: "" (пустая строка) - модель не передаётся
- Applied default gray color - цвет не применяется
- Failed to create NPC visual - ошибка загрузки модели
- T-поза - анимации не работают
