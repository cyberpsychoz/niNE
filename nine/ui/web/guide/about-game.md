# Об игре

## D&D 5e

niNE использует правила **Dungeons & Dragons 5th Edition** для боевой системы и создания персонажей.

### Расы
- Человек, Эльф, Дварф, Полуэльф, Полурослик, Тифлинг

### Классы
- Воин, Маг, Жрец, Плут, Следопыт, Паладин, Варвар, Бард, Друид, Колдун, Чародей, Монах

### Боевая система
- Пошаговый бой с инициативой (d20 + DEX)
- Экономика действий: действие, бонусное действие, движение, реакция
- 35 заклинаний с системой слотов и концентрации
- Состояния D&D 5e (ослепление, паралич, оглушение и др.)
- Короткий и длинный отдых с Hit Dice

### NPC
- ECS-система с ИИ разного уровня детализации (LOD)
- Поведения: патруль, блуждание, преследование, атака, бегство
- Потребности: голод, усталость, социальные нужды
- Фракции с системой друг/враг
- Расписания (работа, еда, сон)

## Мультиплеер

Клиент-серверная архитектура с шифрованием SSL/TLS. Мастер управляет сервером, игроки подключаются через IP.
