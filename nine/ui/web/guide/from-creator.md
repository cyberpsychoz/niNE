# От создателя

Добро пожаловать в **niNE** — мультиплеерный 3D-движок для настольных ролевых игр!

## Что это?

niNE — это онлайн-платформа для проведения D&D сессий в 3D. Мастер (DM) создаёт мир, управляет NPC и ведёт историю, а игроки создают персонажей и взаимодействуют с миром.

## Как начать?

1. **Создайте персонажа** — выберите расу, класс и характеристики
2. **Подключитесь к серверу** — введите IP адрес и никнейм
3. **Играйте** — исследуйте мир, общайтесь, участвуйте в боях

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Передвижение |
| Мышь | Камера |
| T | Открыть чат |
| I | Лист персонажа |
| K | Книга заклинаний |
| J | Журнал квестов |
| F2 | Панель DM (для мастеров) |
| ESC | Меню паузы |

## Чат-команды

- `/me <действие>` — действие от первого лица
- `/it <текст>` — безличное действие
- `/ooc <текст>` — внеигровой чат
- `/looc <текст>` — локальный внеигровой чат
- `/help` — список всех команд
